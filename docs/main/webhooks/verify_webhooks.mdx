# Verify webhook signatures

Pay Theory signs every webhook with an Ed25519 key. Verify the signature before you act on a request, so a request someone else sends to your endpoint is rejected.

Verification runs on your server with a public key you fetch once. It needs no call to Pay Theory per request.

***

## What Pay Theory signs

Each request has three headers:

| Header | Value |
|---|---|
| `X-Webhook-Signature` | Base64 Ed25519 signature, 64 bytes once decoded. |
| `X-Webhook-Timestamp` | Unix time in seconds when Pay Theory sent this attempt. |
| `X-Webhook-Key-Id` | The `kid` of the key that signed the request. |

The signature covers the timestamp, a period and the raw request body:

```text title="Signed bytes"
<X-Webhook-Timestamp>.<raw request body>
```

Use the body bytes exactly as they arrived. If your framework parses the JSON and you serialize it again, the bytes change and the signature fails.

***

## 1. Get the public key

Call the `jwks` query with the same environment's partner or merchant secret key. Both return the same key.

```graphql title="Example query"
query WebhookVerificationKeys {
  jwks {
    keys {
      kid
      kty
      crv
      alg
      use
      x
    }
  }
}
```

```json title="Response"
{
  "data": {
    "jwks": {
      "keys": [
        {
          "kid": "key-1",
          "kty": "OKP",
          "crv": "Ed25519",
          "alg": "EdDSA",
          "use": "sig",
          "x": "vpr_qZecTM6euIor3KpvjDx89OqAsCWUeAf7lLaKTIo"
        }
      ]
    }
  }
}
```

Save `data.jwks` in your receiver's configuration, one copy per environment. The sandbox and live keys are different. There is no public URL for the keys, so fetch them with your API key when you deploy, not on each request.

If a request arrives with an unknown `X-Webhook-Key-Id`, run the query again to pick up a new key.

***

## 2. Verify each request

For every request:

1. Read the three headers.
2. Reject the request if `X-Webhook-Timestamp` is more than 5 minutes from your server's clock. This stops someone replaying an old request.
3. Find the key whose `kid` matches `X-Webhook-Key-Id`.
4. Verify the signature over `<timestamp>.<raw body>` with that key.
5. Parse the JSON only after the signature passes.

Return a `4xx` status for a request that fails, and don't process it.

### Node.js

This module uses only Node's built-in `crypto`.

```javascript title="verify_webhook.mjs"
import { createPublicKey, verify } from 'node:crypto';

const TOLERANCE_SECONDS = 5 * 60;
const BASE64 = /^(?:[A-Za-z0-9+/]{4})*(?:[A-Za-z0-9+/]{2}==|[A-Za-z0-9+/]{3}=)?$/;

function header(headers, name) {
  const match = Object.entries(headers).find(
    ([key]) => key.toLowerCase() === name.toLowerCase(),
  );
  const value = match?.[1];
  if (typeof value !== 'string' || value.length === 0) {
    throw new Error(`Missing ${name} header`);
  }
  return value;
}

/**
 * Verify a Pay Theory webhook and return the parsed event.
 *
 * @param {object} options
 * @param {Buffer} options.rawBody The exact request body bytes. Do not parse it first.
 * @param {Record<string, string | string[] | undefined>} options.headers The request headers.
 * @param {{keys: Array<{kid: string, kty: string, crv: string, alg: string, use: string, x: string}>}} options.jwks
 *   The result of the `jwks` GraphQL query.
 * @param {number} [options.nowSeconds] Current Unix time in seconds.
 * @returns {{event: string, subtype: string, payload: object, event_id: string, occurred_at: string}}
 */
export function verifyWebhook({
  rawBody,
  headers,
  jwks,
  nowSeconds = Math.floor(Date.now() / 1000),
}) {
  if (!Buffer.isBuffer(rawBody)) {
    throw new Error('rawBody must be the raw request Buffer');
  }
  const signature = header(headers, 'X-Webhook-Signature');
  const timestamp = header(headers, 'X-Webhook-Timestamp');
  const keyId = header(headers, 'X-Webhook-Key-Id');

  // 1. Reject old or future timestamps to stop replayed requests.
  if (!/^[0-9]+$/.test(timestamp)) {
    throw new Error('Invalid webhook timestamp');
  }
  if (Math.abs(nowSeconds - Number(timestamp)) > TOLERANCE_SECONDS) {
    throw new Error('Webhook timestamp is outside the 5-minute window');
  }

  // 2. Find the public key named in the X-Webhook-Key-Id header.
  const jwk = jwks.keys.find((key) => key.kid === keyId);
  if (!jwk || jwk.kty !== 'OKP' || jwk.crv !== 'Ed25519') {
    throw new Error('Unknown webhook key ID');
  }
  const publicKey = createPublicKey({
    key: { kty: jwk.kty, crv: jwk.crv, x: jwk.x },
    format: 'jwk',
  });

  // 3. Verify the signature over `<timestamp>.<raw body>`.
  if (!BASE64.test(signature)) {
    throw new Error('Invalid webhook signature encoding');
  }
  const signedBytes = Buffer.concat([Buffer.from(`${timestamp}.`), rawBody]);
  const valid = verify(null, signedBytes, publicKey, Buffer.from(signature, 'base64'));
  if (!valid) {
    throw new Error('Invalid webhook signature');
  }

  // 4. Only now parse the JSON.
  return JSON.parse(rawBody.toString('utf8'));
}
```

Pass it the raw body. With Express, `express.raw` keeps `request.body` as a `Buffer`:

```javascript title="server.mjs"
import express from 'express';
import { verifyWebhook } from './verify_webhook.mjs';

const jwks = JSON.parse(process.env.PAY_THEORY_JWKS);
const app = express();

app.post(
  '/webhooks/paytheory',
  express.raw({ type: 'application/json' }),
  (request, response) => {
    let event;
    try {
      event = verifyWebhook({ rawBody: request.body, headers: request.headers, jwks });
    } catch (error) {
      return response.status(400).send(error.message);
    }
    // Queue the event for processing, then acknowledge.
    queue.add(event);
    response.sendStatus(204);
  },
);
```

### Python

This module uses the [`cryptography`](https://pypi.org/project/cryptography/) package.

```python title="verify_webhook.py"
import base64
import binascii
import json
import time

from cryptography.exceptions import InvalidSignature
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PublicKey

TOLERANCE_SECONDS = 5 * 60


class WebhookVerificationError(Exception):
    pass


def _header(headers, name):
    for key, value in headers.items():
        if key.lower() == name.lower() and value:
            return value
    raise WebhookVerificationError(f"Missing {name} header")


def verify_webhook(raw_body: bytes, headers: dict, jwks: dict, now_seconds: int | None = None) -> dict:
    """Verify a Pay Theory webhook and return the parsed event.

    raw_body: the exact request body bytes. Do not parse it first.
    headers: the request headers.
    jwks: the result of the `jwks` GraphQL query, for example {"keys": [...]}.
    """
    signature = _header(headers, "X-Webhook-Signature")
    timestamp = _header(headers, "X-Webhook-Timestamp")
    key_id = _header(headers, "X-Webhook-Key-Id")

    # 1. Reject old or future timestamps to stop replayed requests.
    if not timestamp.isdigit():
        raise WebhookVerificationError("Invalid webhook timestamp")
    now = int(time.time()) if now_seconds is None else now_seconds
    if abs(now - int(timestamp)) > TOLERANCE_SECONDS:
        raise WebhookVerificationError("Webhook timestamp is outside the 5-minute window")

    # 2. Find the public key named in the X-Webhook-Key-Id header.
    jwk = next((key for key in jwks["keys"] if key["kid"] == key_id), None)
    if jwk is None or jwk["kty"] != "OKP" or jwk["crv"] != "Ed25519":
        raise WebhookVerificationError("Unknown webhook key ID")
    x = jwk["x"] + "=" * (-len(jwk["x"]) % 4)
    public_key = Ed25519PublicKey.from_public_bytes(base64.urlsafe_b64decode(x))

    # 3. Verify the signature over `<timestamp>.<raw body>`.
    try:
        public_key.verify(
            base64.b64decode(signature, validate=True),
            timestamp.encode("ascii") + b"." + raw_body,
        )
    except (InvalidSignature, binascii.Error, ValueError) as error:
        raise WebhookVerificationError("Invalid webhook signature") from error

    # 4. Only now parse the JSON.
    return json.loads(raw_body)
```

With Flask, `request.get_data()` returns the raw body:

```python title="app.py"
import json
import os

from flask import Flask, request

from verify_webhook import WebhookVerificationError, verify_webhook

JWKS = json.loads(os.environ["PAY_THEORY_JWKS"])
app = Flask(__name__)


@app.post("/webhooks/paytheory")
def paytheory_webhook():
    try:
        event = verify_webhook(request.get_data(), dict(request.headers), JWKS)
    except WebhookVerificationError as error:
        return str(error), 400
    # Queue the event for processing, then acknowledge.
    queue.put(event)
    return "", 204
```

***

## 3. Check the event before you act

A valid signature proves Pay Theory sent the request. Two more checks keep your data correct.

**Check the merchant.** If a route serves one merchant, compare `payload.merchant_uid` with that merchant and reject a mismatch.

**Deduplicate on `event_id`.** Retries reuse the same `event_id`. Record each `event_id` with a unique constraint when you start processing it, and skip an event whose `event_id` is already recorded. If processing fails, remove the record so a retry can try again.

***

## Troubleshooting

| Problem | What to check |
|---|---|
| Every signature fails | Your framework parsed the body. Verify the raw bytes instead. |
| Signatures fail after a deploy | You saved keys from the other environment. Fetch `jwks` with the same environment's API key. |
| Timestamp errors | Your server clock is off. Sync it with NTP. |
| Unknown key ID | Fetch `jwks` again and update your saved keys. |
