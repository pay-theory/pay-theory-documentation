# Payment Method Token

> Part of PayTheory GraphQL API

---

## Operations

| Operation | Type | Description |
| --- | --- | --- |
| [paymentMethodTokens](https://docs.paytheory.com/docs/api/payment-method-token/payment-method-tokens) | Query | Returns payment method tokens. |
| [createPaymentMethod](https://docs.paytheory.com/docs/api/payment-method-token/create-payment-method) | Mutation | This mutation will create a payment method token for a payor. |
| [updatePaymentMethodToDisabled](https://docs.paytheory.com/docs/api/payment-method-token/update-payment-method-to-disabled) | Mutation | This mutation can be used to disable a payment method token. |
| [validatePaymentMethodOwnership](https://docs.paytheory.com/docs/api/payment-method-token/validate-payment-method-ownership) | Query | This mutation validates whether a provided card or bank account number matches a specific payment method. |
