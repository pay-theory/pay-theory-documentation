# Authorization

> Part of PayTheory GraphQL API

---

## Operations

| Operation | Type | Description |
| --- | --- | --- |
| [authorizations](https://docs.paytheory.com/docs/api/authorization/authorizations) | Query | This query will return a list of authorizations for a merchant. |
| [createAuthorization](https://docs.paytheory.com/docs/api/authorization/create-authorization) | Mutation | This mutation will create a new authorization for a merchant. |
| [createWalletAuthorization](https://docs.paytheory.com/docs/api/authorization/create-wallet-authorization) | Mutation | This call is used to create an authorization for a wallet payment via Apple Pay or Google Pay. |
| [createCapture](https://docs.paytheory.com/docs/api/authorization/create-capture) | Mutation | This mutation will capture an authorization for a merchant. |
| [createVoidForAuthorization](https://docs.paytheory.com/docs/api/authorization/create-void-for-authorization) | Mutation | This will void an authorization that has not been captured. |
