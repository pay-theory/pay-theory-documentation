# Settlement

> Part of PayTheory GraphQL API

---

## Operations

| Operation | Type | Description |
| --- | --- | --- |
| [settlements](https://docs.paytheory.com/docs/api/settlement/settlements) | Query | Returns settlements. |
| [availableFundsBalance](https://docs.paytheory.com/docs/api/settlement/available-funds-balance) | Query | This query returns the instructional hold and reserve balances for a merchant, along with the instruction window status. |
| [fundingTransfers](https://docs.paytheory.com/docs/api/settlement/funding-transfers) | Query | Returns funding transfers. |
| [instruction](https://docs.paytheory.com/docs/api/settlement/instruction) | Query | Returns instruction. |
| [cancelSettlementInstruction](https://docs.paytheory.com/docs/api/settlement/cancel-settlement-instruction) | Mutation | Cancels settlement instruction. |
| [createSettlementInstruction](https://docs.paytheory.com/docs/api/settlement/create-settlement-instruction) | Mutation | This mutation creates an instructional funding request for a merchant. |
