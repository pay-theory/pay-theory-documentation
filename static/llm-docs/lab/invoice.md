# Invoice

> Part of PayTheory Lab GraphQL API

---

## Operations

| Operation | Type | Description |
| --- | --- | --- |
| [invoices](https://docs.paytheory.com/api/invoice/invoices) | Query | Returns invoices. |
| [createInvoice](https://docs.paytheory.com/api/invoice/create-invoice) | Mutation | Creates an invoice. |
| [updateInvoice](https://docs.paytheory.com/api/invoice/update-invoice) | Mutation | Updates an invoice. |
| [deleteInvoice](https://docs.paytheory.com/api/invoice/delete-invoice) | Mutation | Deletes an invoice. |
| [createInvoiceEmail](https://docs.paytheory.com/api/invoice/create-invoice-email) | Mutation | This call is used to resend Invoice emails for a specific invoice. |
| [createOfflineTransaction](https://docs.paytheory.com/api/invoice/create-offline-transaction) | Mutation | This call is used to create an offline transaction for an invoice. |
