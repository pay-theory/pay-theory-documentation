# Recurring Payment

> Part of PayTheory GraphQL API

---

## Operations

| Operation | Type | Description |
| --- | --- | --- |
| [recurringPayments](https://docs.paytheory.com/docs/api/recurring-payment/recurring-payments) | Query | Returns recurring payments. |
| [createRecurringPayment](https://docs.paytheory.com/docs/api/recurring-payment/create-recurring-payment) | Mutation | Creates recurring payment. |
| [updateRecurringPayment](https://docs.paytheory.com/docs/api/recurring-payment/update-recurring-payment) | Mutation | Updates recurring payment. |
| [cancelRecurringPayment](https://docs.paytheory.com/docs/api/recurring-payment/cancel-recurring-payment) | Mutation | Once a recurring payment is cancelled, it cannot be reactivated. |
| [missedRecurringPaymentData](https://docs.paytheory.com/docs/api/recurring-payment/missed-recurring-payment-data) | Query | This call will return details you need to display the proper amount to the customer to catch up on missed payments for a recurring payment. |
| [createRetryForFailedRecurringPayment](https://docs.paytheory.com/docs/api/recurring-payment/create-retry-for-failed-recurring-payment) | Mutation | This call will allow you to retry a payment for a recurring payment that is in a Failed state. |
