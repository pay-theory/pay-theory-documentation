# Wallet Transactions Overview

Learn how to integrate digital wallet payments into your application using Pay Theory's wallet transaction APIs.

***

## Basic Setup

1. **Configure your merchant account** - Ensure wallet payments are enabled
2. **Add wallet buttons** - Implement Apple Pay or Google Pay buttons in your UI
3. **Handle wallet tokens** - Capture the payment token from the wallet provider

***

## Processing Wallet Transactions

After receiving a payment token from Apple Pay™, Google Pay™, or Paze™, you can use either our JavaScript SDK or our API to process the transaction:

### Using JavaScript SDK
```javascript title="javascript"
const walletTransaction = await messenger.processWalletTransaction({
  digitalWalletPayload: walletPaymentToken,
  amount: 1000,
  walletType: "APPLE_PAY",
  // Additional transaction details
});
```

**Documentation:** [JavaScript SDK Wallet Transaction](../../../sdk/javascript/messenger/processWalletTransaction)

### Using API
For server-side processing, you can call our wallet APIs directly:

**Documentation:** 
- [API Reference - Create Wallet Transaction](../../../api/transaction#create-wallet-transaction)
- [API Reference - Create Wallet Authorization](../../../api/authorization#create-wallet-authorization)

***
