# Apple Pay Setup & Requirements

Before implementing Apple Pay, you'll need to configure your Apple Developer account and ensure your environment meets all requirements.

***

## Prerequisites

### 1. Pay Theory Account

You'll need an active Pay Theory account with:
- Valid API credentials (API Key and Merchant ID)
- Configured payment processing
- Access to the Pay Theory dashboard

:::tip Getting Started
Don't have a Pay Theory account yet? [Contact our sales team](https://paytheory.com/contact) to get started.
:::

### 2. Apple Developer Account

Apple Pay requires:
- Enrollment in [Apple Developer Program](https://developer.apple.com/programs/) ($99/year)
- Access to Apple Developer Portal
- Ability to create certificates and identifiers

### 3. Technical Requirements

Your website must have:
- **Valid SSL certificate** (HTTPS required)
- **Domain verification** with Apple
- **Safari 10+** or iOS 10+ support

***

## Step 1: Create Merchant Identifier

1. Log in to [Apple Developer Portal](https://developer.apple.com)
2. Navigate to **Certificates, Identifiers & Profiles**
3. Select **Identifiers** → **Add** (+ button)
4. Choose **Merchant IDs** and click Continue

### Configure Merchant ID

- **Description**: Enter a descriptive name (e.g., "My Company Apple Pay")
- **Identifier**: Use reverse domain notation (e.g., `merchant.com.yourdomain.pay`)

```
Example: merchant.com.mycompany.payments
```

Click **Continue** and then **Register** to create the identifier.

***

## Step 2: Generate Payment Processing Certificate

### Request Certificate from Pay Theory

1. In your merchant identifier settings
2. Under **Merchant Identity Certificate**, click **Create Certificate**
3. You'll need a Certificate Signing Request (CSR)

:::note Important
Contact Pay Theory support at support@paytheory.com to obtain the CSR file needed for certificate generation. Include your merchant ID in the request.
:::

### Upload and Generate Certificate

1. Upload the CSR file provided by Pay Theory
2. Click **Continue** to generate the certificate
3. Download the certificate (`.cer` file)
4. Send the certificate back to Pay Theory support

***

## Step 3: Verify Your Domain

Domain verification proves you control the website where Apple Pay will be used.

### Add Domain

1. In your merchant identifier settings
2. Click **Add Domain** under **Merchant Domains**
3. Enter your domain (e.g., `www.example.com`)
4. Click **Save**

### Download Verification File

1. Click **Download** to get the verification file
2. The file will be named `apple-developer-merchantid-domain-association`

### Upload Verification File

Upload the file to your web server at:
```
https://yourdomain.com/.well-known/apple-developer-merchantid-domain-association
```

:::tip Verification File Location
The file must be accessible at exactly this path. Create the `.well-known` directory if it doesn't exist.
:::

### Verify Domain

1. Return to Apple Developer Portal
2. Click **Verify** next to your domain
3. Apple will check for the verification file
4. Status should change to "Verified"

***

## Step 4: Configure Pay Theory Integration

### Obtain API Credentials

1. Log in to your [Pay Theory Dashboard](https://portal.paytheory.com)
2. Navigate to **API Keys**
3. Copy your:
   - API Key
   - Merchant ID

### Initialize SDK

Add the Pay Theory Messenger SDK to your project:

```html
<script src="https://cdn.paytheory.com/messenger/latest/messenger.js"></script>
```

Initialize with your credentials:

```javascript title="javascript"
const messenger = new PayTheoryMessenger({
  apiKey: 'YOUR_PAY_THEORY_API_KEY',
  environment: 'production' // or 'sandbox' for testing
});
```

- [ ] Pay Theory API credentials obtained
- [ ] Messenger SDK included in project
