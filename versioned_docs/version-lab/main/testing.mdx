### Card Failures

To trigger certain failures process a payment using the following amounts. These failures will not work when using `service_fee` fee mode.

**_These amounts are in cents._**

| Amount | Error Type                             |
| ------ | -------------------------------------- |
| 102    | GENERIC_DECLINE                        |
| 193    | INSUFFICIENT_FUNDS                     |
| 194    | INVALID_ACCOUNT_NUMBER                 |
| 889986 | ADDRESS_VERIFICATION_FAILED_RISK_RULES |
| 889987 | CVV_FAILED_RISK_RULES                  |
| 888888 | DISPUTE                                |

For a complete list of failure codes and their descriptions, see the [Failure Codes documentation](after_payments/failed_transactions).

:::note Triggering a dispute
If you want to trigger a dispute in sandbox, run a transaction for `888888`. You will get a success back and a dispute will be generated as well from this transaction.
:::

## Sandbox API Calls

These GraphQL requests are specifically for testing in sandbox environments and only work when using sandbox credentials (API keys accessing paytheorylab or paytheorystudy).

- [Create Barcode Payment](../api/barcode#create-barcode-payment) - Simulate processing a barcode payment
- [Create Batch Capture](../api/settlement#create-batch-capture) - Trigger a settlement batch creation to test settlement flows

You can also trigger sandbox events using the Sandbox API mutations:

- [Create Sandbox ACH Return](../api/sandbox#create-sandbox-ach-return) - Generate an ACH return for a completed ACH transaction
- [Create Sandbox Dispute](../api/sandbox#create-sandbox-dispute) - Create a dispute for a card transaction
- [Update Sandbox Dispute Status](../api/sandbox#update-sandbox-dispute-status) - Move a dispute to a new status
- [Prepare Sandbox Settlement Batch](../api/sandbox#prepare-sandbox-settlement-batch) - Lock in line items and calculate settlement totals
- [Create Sandbox Settlement](../api/sandbox#create-sandbox-settlement) - Create a settlement from a prepared batch
