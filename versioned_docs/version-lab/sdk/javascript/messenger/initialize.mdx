# initialize

Connects the Messenger to Pay Theory. Call it before any other Messenger function.

***
## Function

```javascript
await messenger.initialize()
```

***
## Parameters

This function takes no parameters.

***
## Returns

```javascript
{
  success: Boolean
  error: String
}
```

| Key | type | description |
|-----|------|-------------|
| success | Boolean | `true` when the Messenger connected. |
| error | String | Why the connection failed, when `success` is `false`. |

***
## Usage

```javascript
const messenger = new paytheory.PayTheoryMessenger({
  apiKey: 'your-api-key'
});

const result = await messenger.initialize();

if (result.success) {
  // Messenger is ready for operations
} else {
  console.error('Initialization failed:', result.error);
}
```

***
## Notes

- `initialize` adds a hidden iframe to the page and opens a secure channel to Pay Theory through it.
- Calling it again on a connected Messenger returns `success: true` without reconnecting.
- If it fails, call it again to retry.
- The [`ready`](./on) event fires when the connection opens.
