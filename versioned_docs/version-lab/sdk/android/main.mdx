# Pay Theory Android SDK

This is the Pay Theory Android SDK. It is a collection of Material Design UI components and utilities to help you integrate Pay Theory into your Android application.

This guide will walk you through the basic steps to integrate the Pay Theory Android SDK into your application.

## Step 1: SDK Setup and Configuration

The Pay Theory Android SDK is available through Maven Central. Follow these steps to set up the SDK in your project:

### Add Maven Repository

Add mavenCentral() to your project level `build.gradle` file:

```groovy
buildscript {
    repositories {
        mavenCentral()
    }
}
```

### Add SDK Dependency

Add Pay Theory Android SDK to your app level `build.gradle` file:

```groovy
dependencies {
    implementation group: 'com.paytheory.android.sdk', name: 'AndroidSDK', version: 'LATEST_VERSION'
}
```

### Configure Build Settings

Update your app level `build.gradle` to set the required SDK versions:

```groovy
android {
    compileSdk 33
    
    defaultConfig {
        minSdk 26
        targetSdk 33
    }
}
```

### Secure Your API Key

While Pay Theory's API key is not considered a secret key, it's best practice to avoid exposing it in your source code repository. Here's how to add it as a build resource:

1. Add your API key to the project level `local.properties` file:
```properties
API_KEY=YOUR-API-KEY
```

2. Update your app level `build.gradle` to read and use the API key:
```groovy
// Read local properties
File secretPropsFile = project.rootProject.file('local.properties')
Properties p = new Properties()
new FileInputStream(secretPropsFile).withCloseable { is -> p.load(is) }
p.each { name, value -> ext[name] = value }

android {
    buildTypes {
        debug {
            resValue("string", "api_key", "${API_KEY}")
        }
        release {
            resValue("string", "api_key", "${API_KEY}")
        }
    }
}
```

## Step 2: Register Your App

Before using the SDK in production, you need to register your app for App Attestation in the Pay Theory Portal:

1. Log in to the Pay Theory Portal
2. Navigate to Settings
3. Find the Native App Registration section
4. Register your Android app with your bundle identifier (e.g., `com.paytheory.android.testsdk`)

:::note
For detailed instructions on app registration, see the [App Registration](app_registration.mdx) guide.
:::

## Step 3: Configure Your Activity

Your payment activity needs to extend `PayTheoryMerchantActivity` and implement the `Payable` interface to handle payment responses:

```kotlin
class PaymentActivity : PayTheoryMerchantActivity(), Payable {
    private lateinit var payTheoryFragment: PayTheoryFragment
    
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_payment)
        
        // Initialize PayTheoryFragment
        payTheoryFragment = PayTheoryFragment()
        initializePayTheoryActivity(payTheoryFragment)
    }
    
    // Required Payable interface handlers
    override fun handleReady() {
        // SDK is ready to accept payments
    }
    
    override fun handleError(error: PTError) {
        runOnUiThread {
            // Handle error state
        }
    }
    
    override fun handleSuccess(result: SuccessfulTransactionResult) {
        runOnUiThread {
            // Handle successful payment
        }
    }
    
    override fun handleFailure(result: FailedTransactionResult) {
        runOnUiThread {
            // Handle failed payment
        }
    }
    
    override fun handlePaymentStart() {
        runOnUiThread {
            // Payment process started
        }
    }
}
```

## Step 4: Create Your Layout

Create a layout file that includes the `PayTheoryFragment` and `PayTheoryButton`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <androidx.fragment.app.FragmentContainerView
        android:id="@+id/payment_fragment"
        android:name="com.paytheory.android.sdk.fragments.PayTheoryFragment"
        android:layout_width="match_parent"
        android:layout_height="wrap_content" />

    <com.paytheory.android.sdk.view.PayTheoryButton
        android:id="@+id/submit_button"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:text="@string/submit_payment" />

</LinearLayout>
```

## Step 5: Configure Payment Settings

Configure your payment settings using the `configurePayment` function:

```kotlin
payTheoryFragment.configurePayment(
    apiKey = getString(R.string.api_key),
    amount = 1000, // Amount in cents
    paymentParameters = PaymentParameters(
        paymentType = PaymentType.CARD,
        requireName = true,
        requireBillingAddress = false
    )
)
```

## Step 6: Set Up Payment Button

Configure the `PayTheoryButton` with a click listener to process the payment:

```kotlin
findViewById<PayTheoryButton>(R.id.submit_button).setOnClickListener {
    payTheoryFragment.transact()
}
```

:::note Alternative: Tokenizing Payments
Instead of immediately processing a payment with `transact()`, you can tokenize a payment method for later use:

```kotlin
// Configure tokenization
payTheoryFragment.configureTokenize(
    apiKey = getString(R.string.api_key),
    paymentParameters = PaymentParameters(
        paymentType = PaymentType.CARD,
        requireName = true
    )
)

// Set up button for tokenization
findViewById<PayTheoryButton>(R.id.submit_button).setOnClickListener {
    payTheoryFragment.tokenize()
}
```
:::

## Complete Example

Here's a complete example putting it all together:

```kotlin
class PaymentActivity : PayTheoryMerchantActivity(), Payable {
    private lateinit var payTheoryFragment: PayTheoryFragment
    
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_payment)
        
        payTheoryFragment = PayTheoryFragment()
        initializePayTheoryActivity(payTheoryFragment)
        
        // Configure payment
        payTheoryFragment.configurePayment(
            apiKey = getString(R.string.api_key),
            amount = 1000,
            paymentParameters = PaymentParameters(
                paymentType = PaymentType.CARD,
                requireName = true,
                requireBillingAddress = false
            )
        )
        
        // Set up payment button
        findViewById<PayTheoryButton>(R.id.submit_button).setOnClickListener {
            payTheoryFragment.transact()
        }
    }
    
    override fun handleReady() {
        Log.d("PayTheory", "SDK Ready")
    }
    
    override fun handleError(error: PTError) {
        runOnUiThread {
            Toast.makeText(this, "Error: ${error.error}", Toast.LENGTH_SHORT).show()
        }
    }
    
    override fun handleSuccess(result: SuccessfulTransactionResult) {
        runOnUiThread {
            Toast.makeText(this, "Payment Successful!", Toast.LENGTH_SHORT).show()
        }
    }
    
    override fun handleFailure(result: FailedTransactionResult) {
        runOnUiThread {
            Toast.makeText(this, "Payment Failed", Toast.LENGTH_SHORT).show()
        }
    }
    
    override fun handlePaymentStart() {
        runOnUiThread {
            Toast.makeText(this, "Processing Payment...", Toast.LENGTH_SHORT).show()
        }
    }
}
```
